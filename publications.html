JSEP Cross-Repository Software Defect Prediction: A Leave-One-Repository-Out Empirical Study Across Five Mature Open-Source Projects ▶
Status: Under review · revision submitted Venue: Wiley Journal of Software: Evolution and Process In review since: June 2026

Abstract. Systematic leave-one-repository-out validation reveals an AUC–F1 asymmetry under cross-repository conditions and identifies defect-rate mismatch as the primary qualitative predictor of transfer degradation. Cross-repository AUC ranges 0.817–0.913 (mean 0.867); cross F1 ranges 0.525–0.707 (mean 0.631).

Discover Computing Risk Based Software Test Prioritization Using Machine Learning Defect Prediction on Five Open Source Repositories ▶
Status: Under review Venue: Springer Discover Computing In review since: August 2026

Abstract. Top-k coverage analysis at k ∈ {10, 20, 30, 40, 50}% with risk-vs-random lift factors. The top 10% of files ranked by predicted risk capture 43.82% of defects (4.37× lift over random). STVR Self-Healing Test Automation via Tree-Ensemble Locator Ranking: An Empirical Evaluation on 2,400 Mutation Events Across Seven Refactoring Classes ▶
Status: Under review Venue: Wiley Software Testing, Verification and Reliability In review since: June 2026

Abstract. A framework that recovers broken UI locators at runtime using DOM similarity analysis and tree-ensemble ranking over eight feature families (id-stability, role/aria, structural neighbourhood, text proximity, depth, attribute Jaccard, sibling index, and XPath edit distance). A mutation-based evaluation pipeline simulates realistic UI evolution across 2,400 mutation events in seven refactoring classes; hybrid heuristic + ML ranking yields a deterministic top-1 candidate with calibrated confidence to gate auto-heal versus flag-for-review.

In prep Process-Metric-Based Software Defect Prediction at Scale: An Empirical Evaluation of Six Machine Learning Classifiers Across 296,457 File Instances from Five Open-Source Systems ▶
Status: Manuscript in preparation

Abstract. Uniform empirical comparison of six classifiers (LR, DT, RF, GB, XGB, MLP) on a 296,457-instance dataset assembled from five mature open-source systems (Elasticsearch, Spring Boot, Hadoop, Kafka, Express). Stratified 5-fold cross-validation with paired-t and Wilcoxon significance testing. Random Forest is best (AUC 0.8998); XGBoost is the closest competitor (AUC 0.8955). Includes multi-model Gini feature importance with explicit caveats on high-cardinality bias.
